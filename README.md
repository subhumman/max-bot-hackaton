# 🏠 MAX Equipment Bot

**Чат-бот учёта сроков службы оборудования в МКД**  
Платформа: [MAX](https://max.ru) · Хакатон · Python

Бот: https://max.ru/t315_hakaton_max_bot

---

## Проблема

Управляющие компании и собственники ведут учёт десятков приборов: счётчики, насосы, бойлеры, автоматы.  
Данные разбросаны по актам, Excel.

**Боли:**
- нет единой картины по дому
- нет упреждающих напоминаний
- подбор аналога - отдельный квест
- замена всегда аварийная, а не плановая

---

## Решение

Чат-бот в MAX, который:

1. Хранит карточки оборудования (тип, модель, дата установки, нормативный срок)
2. Показывает остаток срока и статус 🟢 / 🟡 / 🔴
3. Напоминает за 90 / 30 / 7 дней до замены
4. Подсказывает совместимые аналоги
5. Даёт диспетчеру УК сводку по всему фонду

Всё - в мессенджере, без отдельного приложения и Excel.

---

## Роли

| Роль | Доступ |
|------|--------|
| **Собственник** | Свой дом, устройства, подписки, напоминания |
| **Диспетчер УК** | Всё то же + сводка по всем домам УК (пароль) |

Пароль диспетчера (демо): `uk2026`

---

## Сценарий демо (60–90 сек)

/start
- Город (Москва / Казань / СПб)
- УК
- Дом (ЖК)
- Кто вы? - Собственник / Диспетчер УК
- «Что скоро менять» - карточка просроченного
- «Напомнить» - 7 / 30 / 90 дней
- (для УК) «Сводка по УК» - 🔴 3 · 🟡 7 · 🟢 42

---

## Стек

- **Python 3.11+**
- **maxapi** - клиент MAX Bot API
- **SQLite** (aiosqlite) - устройства, пользователи, подписки
- **APScheduler** - ежедневные напоминания
- **Long polling** (локально) / **Webhook** (прод)

## Быстрый старт

```bash
git clone <repo>
cd max_equipment_bot

python -m venv .venv
# Windows:
.venv\Scripts\activate
# Linux/macOS:
source .venv/bin/activate

pip install -r requirements.txt

# токен в .env
echo MAX_BOT_TOKEN=ваш_токен > .env

python seed.py    # демо-данные
python main.py    # long polling
``` 

## Структура проекта
